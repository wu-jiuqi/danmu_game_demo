# 百味饭馆 · 弹幕经营 H5 Demo

这是按照 `docs/百味饭馆_H5实现方案_v1.md` 与本地直播间原型搭建的离线浏览器 Demo。技术栈为 React + TypeScript + Vite，桌面端展示经营舞台，窄屏端会折叠成直播间竖屏流；界面使用 CSS 与 Emoji 占位图完成，不接真实直播平台。

## 启动

```bash
npm install
npm run dev
```

构建与预览：

```bash
npm run build
npm run preview
```

规则测试：

```bash
npm test
```

## 当前已实现

- 客人到访、排队、落座、点单、灶眼烹饪、待出餐、手动出餐、用餐结账和流失。
- 单一 `tick` 推进所有剩余时间；支持暂停、1 倍、2 倍、5 倍。
- 顶部资源栏（含铭牌碎片和 LIVE 标识）、排队区、全容量桌位区、全容量灶眼区、独立待出餐区、12 道菜菜单/研发、升级信息和事件日志。
- 直播间礼物面板固定展示五种礼物及其当前层数、倒计时、冷却和使用入口；礼物点击统一进入状态机，不绕过容量或订单规则。
- 红色仙女棒、能量药丸、魔法镜、甜甜圈、炸弹五种礼物的上限、冷却、容量和保底规则。
- 饭馆/厨师升级、12 道菜的数据配置、上架/下架与厨师品级锁定。
- `localStorage` 版本化保存现金、材料、等级和已激活菜品；刷新时在线客人和订单重建。
- 27 个 Vitest 用例覆盖核心闭环与文档验收 T01–T14：排队、烹饪、出餐、超时、流失、研发/上架、饭馆/厨师升级、五种礼物和刷新存档，并回归验证菜品 ID 与菜名始终一致、错链订单不能出餐。
- 模拟弹幕指令：`出餐`、`暂停`、`继续`、`1倍`、`2倍`、`5倍`、`排1`、`排2`、`排3`；底部同时提供可见调试按钮。

## 暂未实现

真实抖音事件适配器、账号/联网排行榜、后端、多店铺、正式美术、音效和移动端原生适配不在当前 Demo 范围内。T01–T14 已有逐项自动化验收测试，正式美术仍待后续替换 SVG/Emoji 占位资源。

## 最复杂的状态处理

所有业务时间都只由 `tick` 推进。UI 不自行倒计时，礼物只能通过 `dispatch` 修改状态；存档只保存成长数据，避免刷新后重复结账或恢复在线订单。
