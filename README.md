# 百味饭馆 · 弹幕经营 H5 Demo

这是按照 `docs/百味饭馆_H5实现方案_v1.md` 与 Figma 原型搭建的离线浏览器 Demo。技术栈为 React + TypeScript + Vite，页面基准为 1440 × 900 桌面经营界面；界面使用 CSS 与 Emoji 占位图完成，不接真实直播平台。

## 启动

```bash
npm install
npm run dev
```

构建与预览：

```bash
npm run build
npm run preview
```

规则测试：

```bash
npm test
```

## 当前已实现

- 客人到访、排队、落座、点单、灶眼烹饪、待出餐、手动出餐、用餐结账和流失。
- 单一 `tick` 推进所有剩余时间；支持暂停、1 倍、2 倍、5 倍。
- 顶部资源栏、排队区、桌位区、灶眼区、待出餐区、菜单/研发、升级和事件日志。
- 红色仙女棒、能量药丸、魔法镜、甜甜圈、炸弹五种礼物的上限、冷却、容量和保底规则。
- 饭馆/厨师升级、12 道菜的数据配置、上架/下架与厨师品级锁定。
- `localStorage` 版本化保存现金、材料、等级和已激活菜品；刷新时在线客人和订单重建。
- 11 个 Vitest 用例覆盖核心闭环、容量、超时、研发上架、礼物上限、药丸保底和坏存档清理。
- 模拟弹幕指令：`出餐`、`暂停`、`1倍`、`2倍`、`5倍`、`排1`、`排2`、`排3`。

## 目录

```text

src/game-data/index.ts   # 饭馆、厨师、菜品、客人、礼物和药丸配置
src/game-engine.test.ts  # 11 个核心闭环与边界测试
src/App.tsx              # 页面布局与交互面板
src/styles.css           # 1440×900 夜市经营视觉与响应式滚动
public/visuals/          # SVG 夜景占位背景
docs/                    # 原始 H5 方案和面试作业要求
assets/concept/          # 冻结的概念图，仅作为视觉标准参考
```

真实抖音事件适配器、账号/联网排行榜、后端、多店铺、正式美术、音效和移动端原生适配不在当前 Demo 范围内。下一步优先补齐 T01–T14 的逐项自动化边界测试，再替换 SVG/Emoji 占位资源。

## 最复杂的状态处理

所有业务时间都只由 `tick` 推进。UI 不自行倒计时，礼物只能通过 `dispatch` 修改状态；存档只保存成长数据，避免刷新后重复结账或恢复在线订单。
